Версия добавляет управление избранным через чат и исправляет несколько проблем интерфейса аукциона.

## Добавлено
- Добавлено добавление предметов в избранное командами `/ah notify <название>` и `/dah notify <название>`.
- Если после `notify` не указано название, используется предмет в основной руке, как в `/ah search`.
- Для `notify` добавлено автодополнение названий предметов, включая названия активных кастомных предметов сервера.

## Исправлено
- Настройки фоновых иконок `auction.decor.black` и `auction.decor.orange` теперь применяются во всех основных GUI pnMarket, где раньше часть фона была захардкожена.
- Исправлено переключение сортировки: порядок кликов теперь совпадает с порядком, показанным в lore, без перескакивания через пункт.
- Проверка обновлений pnMarket адаптирована к текущему API pnLibrary и репозиторию `pnFolder/pnMarket`.

## Совместимость
- Paper 1.16.5
- Java 17
- ProtocolLib обязателен
